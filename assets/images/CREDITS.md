## WordPress Photo Directory (CC0)

The WordPress Photo Directory's licence page
(https://wordpress.org/photos/license/) says contributors submit original work under **CC0**, "usable anywhere,
for any purpose, without the need for permission, attribution, or payment". Every submission is moderated.

Each file below was **individually verified on 2026-11-10**: its own photo page was fetched and contained the
directory's attribution block "CC0 licensed photo by …". Credit isn't legally required under CC0; it's recorded here
as good practice and so that provenance can be audited.

Not used: StockSnap and rawpixel results from Openverse. Their source pages couldn't be reached to confirm the licence
(Cloudflare bot checks), and Openverse states it doesn't guarantee licence accuracy.

## Wikimedia Commons (CC BY-SA / CC BY)

The WordPress Photo Directory has no photographs of the candle-making process itself (pouring, moulds, hands at the
bench) or of raw materials, so these come from Wikimedia Commons. Each file was **individually verified on 2026-11-10**:
- **Own-work files:** the Commons file page was fetched and carried the author's own licence statement ("I, the
  copyright holder of this work, hereby publish it under the following license"). The Commons API metadata gave the
  same licence, author and "Own work" credit.
- **`community/candle-dipping-together`:** imported from Panoramio. Its licence (CC BY 3.0) was confirmed by Commons'
  Panoramio licence review (`Panoramioreview` template on the file page), and the original Panoramio page is archived
  (link below).

**Attribution is a licence condition here, unlike CC0.** Each photo has a visible credit line on the page
(author → file page, licence → licence deed). Keep that line if the image moves. The WebP files are resized
adaptations of the originals. CC BY-SA files are distributed under the same licence (ShareAlike); CC BY files only
require attribution. The CSS warm grade (`.img-graded`) is applied in the browser and doesn't change the files. All EXIF
data, including GPS, was stripped on conversion.

**Kit images are material stand-ins, not the product.** The two `kits/` photos show beeswax, a typical kit material.
The alt text describes only what is pictured and never claims it is the Ember & Wick kit. No brand or label is visible
(the only lettering is "BEESWAX", embossed on the bars). Replace them with the studio's own kit photography once it
exists.
