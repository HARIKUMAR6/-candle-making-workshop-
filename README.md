# Ember & Wick — Candle Making Workshop

A static website built with HTML5, Tailwind CSS v4 (CLI) and vanilla JavaScript.

```bash
npm install
npm run dev        # builds CSS, watches it, serves http://localhost:5173
npm run build      # minified CSS → assets/css/styles.css
```

- Design system and architecture: [docs/DESIGN-SYSTEM.md](docs/DESIGN-SYSTEM.md)
- Living style guide: `/styleguide.html`

Edit CSS in `src/css/`. Never edit `assets/css/styles.css`; it is generated.
